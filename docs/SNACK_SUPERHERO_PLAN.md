## 🧭 ميثاق الجدوى التقنية (Technical Feasibility Rules)

> [!IMPORTANT]
> **قواعد ذهبية لحماية المشروع من الأوهام التقنية:**
> 1. **ممنوع محاولة قراءة مؤشر الفأرة (Text Caret Selection)**: برنامج After Effects لا يوفر أي API لمعرفة الكلمة المحددة بمؤشر الفأرة داخل الـ Viewer. البديل الإلزامي والمستقر هو **نظام الوسوم `[كلمة]`** أو الاختيار المباشر.
> 2. **ممنوع الـ Speech-to-Text المحلي داخل السكربت**: محرك ExtendScript محدود بـ ES3 ولا يملك بيئة معالجة صوتية. البديل القياسي هو **المزامنة مع ماركرز التايملاين (Marker-Driven)**.
> 3. **حماية التشكيل العربي (Shaping-Safe)**: أي قياس لمواقع الكلمات يتم **حصراً عند حدود الكلمات والمسافات `\s+`** لضمان عدم انفصال الحروف المتصلة (Ligatures) في العربية.
> 4. **أمان الـ Expressions**: لا يتم استدعاء دوال ثقيلة داخل التعبيرات كل فريم لتفادي هبوط معدل الإطارات (FPS Drop).

- [x] **T1.1**: بناء معالج الوسوم النصية (Syntax Parser) في ExtendScript (`extractTags` و `stripTags`) لاستخراج الكلمات المستهدفة ومواقعها داخل النص دون تشويه النص المعروض.
- [x] **T1.2**: تطوير خوارزمية قياس الكلمات `scanTargetBoxes`:

  - دعم الحساب السليم لاتجاه RTL (العربية) و LTR (الإنجليزية) ومحاذاة المنتصف.
  - الحفاظ التام على ترابط الحروف العربية (Shaping Integrity) وتجاوز مشكلة اقتطاع المسافات عبر قياس `rUpTo.width - rTarget.width`.
- [x] **T1.3**: توليد طبقات الهايلايت المستقلة لكل كلمة مستهدفة مع ربط Expressions الأبعاد والموقع بالكلمة بدقة وتكيف مع `fontRatio`.
- [x] **T1.4**: اختبار توافق محرك الكلمات مع أنماط النص النقطي (Point Text) وصندوق النص (Area Text).

### ⚡ المرحلة 3: فيزياء الحركة الخاطفة (Snappy Physics & Pop Motion)
*الهدف: تحريك خاطف ومبهر يشد العين فوراً (Pattern Interrupt).*

- [x] **T3.1**: حركة الارتداد المرن **Scale Pop Animation**:
  - إضافة حركة قفز سريعة في الحجم (80% -> 118% -> 100%) باستخدام معادلة Overshoot Elastic رياضية في الـ Expression على خاصية Scale.
- [x] **T3.2**: حركة القطع الفوري **Snap Cut (0-Frames)**:
  - ظهور الهايلايت في فريم واحد (0.04 ثانية) مع نبرة الكلام بدون مسار تدريجي بطيء.
- [x] **T3.3**: خيار الـ Smooth Reveal والتحكم بالنعومة (`KeyframeEase(0, 65)`).
- [x] **T3.4**: ضمان توافق محرك الحركة الجديد مع خيارات الحركة التتابعية (Sequential) والمتداخلة (Stagger) وحركة الخروج (Outro Exit).
- [x] **T3.5**: محرك تتبع الـ Typewriter التناسبي للأسطر والفقرات (**Character-Proportional Typewriter Sync**):
  - خوارزمية التوزيع الزمني التناسبي لعدد الحروف: مدة السطر = `totalTypingDuration * (lineChars / totalChars)`.
  - استكشاف تلقائي للـ Text Animators السابقة على طبقة النص (`detectTextAnimator`) وقفل التوقيت عليها فورياً.
  - إنشاء تلقائي للـ Animator الأصلي `Typewriter Sync` على طبقة النص إن لم يكن موجوداً لضمان التطابق البصري المتزامن 1:1.
  - استخدام Keyframes خطية (Linear Interpolation) لمنع انحراف السرعة الحرفية، مع تنظيف تام عند أمر Clear.
- [x] **T3.6**: محرك الحساب الرياضي التراكمي الدقيق للحروف (**Subpixel Exact Character Offsets Array - cOffsets**):
  - القضاء التام على التأخر (Lag) والتوقع التقريبي الخطي (`baseW * p`) الذي كان يفترض تساوي عروض الحروف.
  - قياس مصفوفة العروض التراكمية الحقيقية لكل حرف بالبيكسل (`cOffsets`) عبر محرك After Effects الأصلي مع الحفاظ على عروض المسافات وعلامات الترقيم والتراكيب العربية.
  - حقن المصفوفة في تعبيرات الحجم والموضع (`sizeExpr` و `posExpr`) لقفزات حرفية أو تدرج ناعم يطابق مؤشر الكتابة حرفاً بحرف دون أي مسافة فارغة أو تقدم أو تأخر.
